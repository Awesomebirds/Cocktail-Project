# 칵테일 이미지 추가 안내

칵테일 사진 이미지를 추가하려면 아래 규칙에 맞게 이 폴더(`images/`)에 이미지 파일을 넣어주세요.

## 파일명 규칙
각 칵테일의 고유 코드(ID)를 파일명으로 사용합니다.

예시:
- 진 토닉: `GIN-001.jpg`
- 진 리키: `GIN-002.jpg`
- 보드카 토닉: `VOD-001.jpg`
- 마가리타: `TEQ-001.jpg`
- 사쿠라오 하이볼: `WHI-001.jpg`
- 아마레또 사워: `LIQ-001.jpg`
- 초콜릿 마티니 스타일: `DES-001.jpg`

## 권장 사양
- 비율: 1:1 정사각형 권장
- 해상도: 400x400 ~ 800x800 px 권장
- 포맷: jpg (또는 png)

* 이미지가 없는 칵테일은 시스템 내장 벡터 글래스 일러스트(하이볼, 마티니, 온더락 잔)가 자동으로 표시됩니다.
